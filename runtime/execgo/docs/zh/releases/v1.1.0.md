# ExecGo v1.1.0 发布说明

`v1.1.0` 聚焦于把 ExecGo 明确定位为通用 Agent 的可靠执行层，并补齐成熟 Agent adapter、取消语义与 runtime 集成文档。

## 版本亮点

- 明确 ExecGo 的推荐边界：Agent 负责规划、上下文理解与工具选择；ExecGo 负责执行前校验、依赖调度、重试/超时/取消、状态持久化与审计。
- 面向 Codex、Claude Code、Hermes Agent、OpenClaw 等成熟 Agent，整理结构化 action 接入路径。
- 强化任务取消语义与 CLI 取消工作流，便于长任务收敛到清晰终态。
- 更新 ExecGo 与 `execgo-runtime` 的职责关系：ExecGo 是控制面执行层，runtime 是进程级数据面运行时。

## 主要变更

### 1) 通用 Agent 可靠执行层

- 文档入口更新为“通用 Agent 如何采用 ExecGo”。
- Adapter 文档更清晰地区分 `/adapters/tools`、`/adapters/actions`、`/adapters/translate` 与直接 `POST /tasks`。
- 补充 agent/ExecGo/runtime 三方边界，避免把 ExecGo 误解为完整 Agent 框架。

### 2) 取消与运行时集成

- 补强任务取消状态流与 CLI 取消路径。
- 说明 `runtime.command` / `runtime.script` 适合需要进程执行、资源限制或沙箱策略的动作。

### 3) 版本一致性

- 核心版本号更新为 `v1.1.0`。
- `/health` 中的 `version` 字段继续使用 `pkg/version.Current` 作为单一来源。

## 升级建议

- 下游依赖建议升级到 `v1.1.0`：
  - `github.com/iammm0/execgo`
  - `github.com/iammm0/execgo/contrib/sqlite`

- 若你的部署或灰度逻辑依赖 `/health.version`，请同步预期版本值为 `v1.1.0`。
